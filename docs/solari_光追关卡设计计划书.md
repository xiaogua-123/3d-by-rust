### 4.1 全局切换（已实现）

|------|------|----|----|------|
| 进入 Solari | 按 `6` | 任何常规关卡 | Solari | 移除玩家 → 生成光追场景 + 第一人称相机 |
| 退出 Solari | 按 `6` | Solari | 原关卡 | 清理 → 重生玩家 → 恢复第三人称相机 |

### 4.2 关卡内多机位切换（待实现）

在 Solari 关卡内按 `V` 键循环切换 4 个预设机位：

| 机位 | 位置 (x, y, z) | 朝向 | 说明 |
|------|---------------|------|------|
| 1 自由 | (初始生成位置) | 自由 | 默认 WASD 第一人称 |
| 2 俯视 | (0, 10, 0) | 向下看原点 | 鸟瞰全场景 |
| 3 侧面 | (-8, 3, 0) | 看向金属球 | 观察镜面反射 |
| 4 光源视角 | (0, 3.5, 3) | 看向地面 | 观察间接光照扩散 |

**实现方案：**

```rust
// 新增: src/solari_demo.rs

#[derive(Resource)]
struct SolariViewpoints {
    points: Vec<(Vec3, Vec3)>,  // (位置, 注视点)
    current: usize,
    is_free: bool,  // true = 自由移动, false = 固定机位
}

fn toggle_viewpoint(
    keys: Res<ButtonInput<KeyCode>>,
    mut viewpoints: ResMut<SolariViewpoints>,
    mut cam_q: Query<(&mut Transform, &mut CameraController)>,
) {
    if !keys.just_pressed(KeyCode::KeyV) { return; }
    let Ok((mut cam_t, mut ctl)) = cam_q.single_mut() else { return };

    if viewpoints.is_free {
        // 切到固定机位
        let (pos, look_at) = viewpoints.points[viewpoints.current];
        cam_t.translation = pos;
        cam_t.look_at(look_at, Vec3::Y);
        viewpoints.current = (viewpoints.current + 1) % viewpoints.points.len();
        viewpoints.is_free = false;
    } else {
        // 切回自由模式
        viewpoints.is_free = true;
    }
}
```

## 八、注意事项

1. **材质兼容性**：Solari 光追只支持 `StandardMaterial`，游戏中的 `ToonMaterial` (卡通渲染) 在 Solari 下不会正确渲染。NPC 和收集品需要使用 `StandardMaterial`。

2. **相机冲突**：`CameraControllerPlugin` 和 `CameraPlugin` 同时活跃，但针对不同实体（`CameraController` vs `LookState`+`Player`），互不干扰。光标管理用不同按键（Backspace vs O）。

3. **性能**：Solari 实时光追对 GPU 要求较高。低端 GPU 可能需要降低分辨率或关闭某些效果。可通过 `SolariLighting` 的参数调整质量。

4. **状态恢复**：退出 Solari 时自动重生玩家到 `(0, 0, 0)`。如需保持退出位置，可在 `PreviousLevel` 资源中添加 `spawn_point` 字段。
