## 一、概述

实现了完整的**时序上采样管线**，包含 velocity compute shader、Catmull-Rom bicubic 上采样、velocity reprojection、neighborhood clamping 防鬼影、A/B ping-pong history 纹理。全部集成到 Bevy Core3d 渲染图中。

### 架构图

```
每帧渲染流程：

Main Pass (低分辨率)
    │
    ├─▶ ViewDepthTexture (深度, 仅 RENDER_ATTACHMENT)
    │
    ├─▶ Velocity Compute Shader                 ──▶ RG16F 运动向量纹理
    │    · 远平面重建世界坐标 (depth=1.0)
    │    · 投影到上一帧 NDC
    │    · 计算 UV 位移量
    │
    └─▶ Fragment Upscale Pass                   ──▶ 全分辨率输出
         · Catmull-Rom bicubic 上采样
         · velocity reprojection
         · neighborhood clamping (3×3)
         · 时序混合 (95% 历史 + 5% 当前)
         · 写入 A/B history 纹理 (ping-pong)
```

## 二、实现细节

### 2.1 Velocity Compute Shader

- 输入: `u_curr` (当前帧 view_proj + inv_view_proj), `u_prev` (上一帧 view_proj)
- 输出: `RG16F` 运动向量纹理
- 原理: 所有像素假设在远平面 (depth=1.0) → 从 inv_view_proj 重建世界坐标 → 投影到上一帧 → NDC 空间 UV 位移
- **限制**: 忽略物体自身运动，近处物体可能有轻微 ghosting

```wgsl
// velocity.wgsl 核心逻辑 (简化)
let uv = (vec2<f32>(id.xy) + 0.5) / vec2<f32>(size);
let ndc = uv * 2.0 - 1.0;
let world_pos_h = u_curr.inv_view_proj * vec4<f32>(ndc, 1.0, 1.0);
let world_pos = world_pos_h.xyz / world_pos_h.w;
let prev_ndc_h = u_prev.view_proj * vec4<f32>(world_pos, 1.0);
let prev_uv = prev_ndc_h.xy / prev_ndc_h.w;
let velocity = (uv * 2.0 - 1.0) - prev_uv;
textureStore(output_velocity, id.xy, vec4(velocity * 0.5, 0.0, 0.0));
```

### 2.2 Temporal Upscale Fragment Shader

1. **Catmull-Rom Bicubic 上采样**: 4×4=16 加权采样，比 bilinear 更锐利
2. **Velocity reprojection**: `history_uv = current_uv - velocity`
3. **Neighborhood clamping**: 在低分辨率颜色周围 3×3 计算 min/max，限制历史颜色范围，防鬼影
4. **时序混合**: `alpha = history_valid ? 0.95 : 0.0`, `result = mix(current, history, alpha)`
5. **History writeback**: `textureStore(history_out, pos, result)` 写入 A/B ping-pong 纹理

### 2.3 A/B Ping-pong History

- 两帧 `RGBA16Float` 纹理轮换
- 偶数帧: read=A, write=B
- 奇数帧: read=B, write=A
- 尺寸随窗口大小变化自动重建

### 2.4 RenderGraph 节点 (DlssUpscaleNode)

```
Core3d 子图:
... → EndMainPass → DlssSuperResolution → StartMainPassPostProcessing → ...
```

单帧内依次执行:
1. Velocity compute shader (8×8 workgroup)
2. Fragment upscale pass (全屏三角形，3 vertices)
3. History 纹理轮换

### 2.5 解决的问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Bevy depth 缺 TEXTURE_BINDING | ViewDepthTexture 只有 RENDER_ATTACHMENT 标志 | 放弃深度纹理，改用远平面相机矩阵计算 velocity |
| Bevy depth 缺 COPY_SRC | 同上 | 同上 |
| Pipeline 格式不匹配 | Upscale 输出 Rgba16Float vs 相机 Rgba8UnormSrgb | 输出改为 Rgba8UnormSrgb，history 保持 Rgba16Float |
| History 从未写入 | Fragment shader 缺 textureStore | 新增 storage texture binding + textureStore 调用 |
