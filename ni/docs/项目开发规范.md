
## 二、开发规范

### 2.1 Rust 代码规范

| 规则 | 说明 |
|------|------|
| `cargo fmt` | 提交前必须格式化 |
| `cargo clippy` | 零警告目标 (现有历史警告逐步清理) |
| 不可变性优先 | `let` 默认, 仅必要时 `let mut` |
| `unwrap()` 限制 | 仅允许在: Startup 系统、测试、逻辑上不可能失败的位置 |
| 错误处理 | 库代码用 `thiserror`, 应用代码用 `anyhow` |
| 魔术数字 | 提取为 `const` 或资源常量 |
| 函数 ≤ 50 行 | 超限拆分 |
| 文件 ≤ 800 行 | 超限提取模块 |

### 2.2 Bevy ECS 规范

```rust
// ✅ 系统参数顺序 (推荐)
fn my_system(
    // 1. 事件读写 (先读后写)
    mut events: MessageReader<SomeEvent>,
    mut writer: MessageWriter<OtherEvent>,
    // 2. 资源 (只读 → 可变)
    time: Res<Time>,
    config: Res<GameplayConfig>,
    mut state: ResMut<NextState<GamePhase>>,
    // 3. Query (细粒度 → 粗粒度)
    player_q: Query<&Transform, With<Player>>,
    mut enemy_q: Query<(&mut Transform, &Enemy)>,
    // 4. Commands 放最后
    mut commands: Commands,
) { /* ... */ }
```

| 规则 | 说明 |
|------|------|
| 事件优于直接调用 | 模块间通信用 `Message` / `MessageReader` / `MessageWriter` |
| `Single<T>` 优先 | 确定只有一个实体时用 `Single` 代替 `Query` |
| `run_if` 状态守卫 | 系统必须用 `run_if(in_state(...))` 限定 GamePhase |
| 资源默认实现 | 所有 Resource 必须实现 `Default` 或 `init_resource` |
| 组件注册 | `#[reflect(Component)]` + `app.register_type::<T>()` |

### 2.3 消息/事件系统规范

```rust
// 1. 定义事件 (Message derive)
#[derive(Message)]
pub struct MyEvent { pub field: Type }

// 2. 注册 (Plugin::build)
app.add_message::<MyEvent>();

// 3. 写入 (MessageWriter)
fn writer_system(mut writer: MessageWriter<MyEvent>) {
    writer.write(MyEvent { field: value });
}

// 4. 读取 (MessageReader)
fn reader_system(mut events: MessageReader<MyEvent>) {
    for ev in events.read() { /* 处理 */ }
}
```

### 2.4 文件命名规范

| 类型 | 命名 | 示例 |
|------|------|------|
| 模块文件 | `snake_case.rs` | `game_state.rs` |
| 组件 | `PascalCase` | `Player`, `CameraController` |
| 资源 | `PascalCase` | `PlayerSettings`, `LevelConfig` |
| 事件 | `PascalCase` + `Event` 后缀 | `LoadLevelEvent` |
| 插件 | `PascalCase` + `Plugin` 后缀 | `CameraPlugin` |
| 系统函数 | `snake_case` | `camera_wasd`, `spawn_level1` |
| 常量 | `UPPER_SNAKE_CASE` | `PITCH_LIMIT` |

### 2.5 注释规范

```rust
/// 公开类型的文档注释 (必须)
pub struct CameraPlugin;

//! 模块级文档注释 (必须)
//! 描述整个模块的用途

// 行内注释 (仅用于非显而易见的逻辑)
// 不写 "做什么" (代码已自解释), 只写 "为什么这样做"
```

## 三、坐标系统与变换规范

### 3.1 Bevy 默认坐标

```
         Y+ (上)
         │
         │
         │
         └──────→ X+ (右)
        ╱
       ╱
      Z+ (前 / 屏幕外)
```

| 轴 | 方向 | 游戏含义 |
|----|------|---------|
| X | 右 | 左右移动 |
| Y | 上 | 高度 / 跳跃 |
| Z | 前 | 前后移动 (Bevy 默认前方) |

### 3.2 坐标代码规范

```rust
// ✅ 使用 Vec3 字面量常量
const SPAWN_POINT: Vec3 = Vec3::new(0.0, 0.5, 0.0);
const NPC_POSITIONS: [Vec3; 3] = [
    Vec3::new(-5.0, 0.0, -3.0),
    Vec3::new(0.0, 0.0, -5.0),
    Vec3::new(5.0, 0.0, -3.0),
];

// ✅ RON 中用元组 (序列化友好)
// spawn_point: (0.0, 0.5, 0.0)

// ✅ RON → Vec3 转换 (spawn_zone 自动处理)
// position: (x, y, z) → Vec3::new(x, y, z)

// ✅ Transform 构造
Transform::from_xyz(x, y, z)                        // 纯位移
Transform::from_translation(Vec3::new(x, y, z))     // 同上
Transform::from_xyz(x, y, z).looking_at(target, Vec3::Y)  // 位移 + 朝向

// ❌ 避免: 用单独的 x/y/z 变量分散坐标
// ❌ 避免: 用 magic number 写死位置
```

### 3.3 RON ↔ Rust 坐标映射

```rust
// RON 定义 → Rust 生成 (spawn_zone / NPC 生成)
pub struct ZoneDef {
    pub spawn_point: (f32, f32, f32),     // → Vec3::new(x, y, z)
    pub floor_size: f32,                  // → Plane3d.size(floor_size, floor_size)
    pub floor_color: (f32, f32, f32),    // → Color::srgb(r, g, b)
}

pub struct ZoneNpcDef {
    pub position: (f32, f32, f32),       // → Transform::from_xyz(x, y, z)
    pub color: (f32, f32, f32),          // → Color::srgb(r, g, b)
}
```

### 3.4 常见尺寸参考

| 对象 | 推荐尺寸 | 备注 |
|------|---------|------|
| 玩家碰撞 | 半径 0.4, 高 1.6 | 略小于视觉模型 |
| NPC 碰撞 | 半径 0.4, 高 1.6 | 同玩家 |
| 收集品 | 半径 0.3 | 漂浮小球 |
| 地面 | 20～40 单位 | 程序化 Plane |
| 墙壁 | 宽 0.5, 高 2.0, 深 8.0 | 薄墙 |
| 平台 | 3.0 × 0.3 × 3.0 | 立方体 |
| 关卡间距 | ≥ 3 单位 | NPC/物体最小间距 |
| 对话触发半径 | 2.5～3.0 | `DialogueTrigger.radius` |

## 四、关卡代码复用设计

### 4.1 两种关卡模式

| 模式 | 驱动方式 | 适用场景 | 文件 |
|------|---------|---------|------|
| **数据驱动 (推荐)** | RON 文件 + `spawn_zone()` | 常规关卡，有 NPC/收集/敌人/过渡 | `level.rs` |
| **代码驱动** | 专用 `spawn_xxx()` 函数 | 特殊关卡 (Solari光追、塔防) | `solari_demo.rs` / `td/` |

### 4.2 数据驱动模式 — 新增关卡只需 3 步

```
步骤 1: 写 RON 文件
    assets/zones/your_zone.ron

步骤 2: 注册枚举
    src/level.rs → GameLevel 枚举 + 4 个方法

步骤 3: 注册系统
    src/level.rs → LevelPlugin::build
        .add_systems(OnEnter(YourLevel), spawn_your_level)
        .add_systems(OnExit(YourLevel),  cleanup_level)
```

#### spawn_your_level 模板 (直接复用 `spawn_zone`)

```rust
fn spawn_your_level(
    mut commands: Commands,
    mut meshes: ResMut<Assets<Mesh>>,
    mut std_materials: ResMut<Assets<StandardMaterial>>,
    mut materials: ResMut<Assets<ToonMaterial>>,
    settings: Res<ToonSettings>,
    mut collectibles: ResMut<LevelCollectibles>,
    config: Res<GameplayConfig>,
    bank: Res<ZoneBank>,
    asset_server: Res<AssetServer>,
) {
    let Some(zone) = bank.zones.get(GameLevel::YourLevel.zone_id()) else {
        error!("找不到区域定义: your_zone");
        return;
    };
    spawn_zone(
        &mut commands, &mut *meshes, &mut *std_materials, &mut *materials,
        &settings, &config, &asset_server, zone, &mut collectibles,
    );
}
```

### 4.3 代码驱动模式 — 特殊关卡模板

```rust
// 在专用模块 (如 my_special.rs) 中:
use crate::level::LevelEntity;

pub(crate) fn spawn_my_special_level(
    commands: &mut Commands,
    meshes: &mut Assets<Mesh>,
    materials: &mut Assets<StandardMaterial>,
    // 按需加参数
) {
    let mesh = meshes.add(Cuboid::default().mesh().build().with_generated_tangents().unwrap());

    commands.spawn((
        Mesh3d(mesh.clone()),
        MeshMaterial3d(materials.add(StandardMaterial::default())),
        Transform::from_xyz(0.0, 0.5, 0.0),
        LevelEntity,  // ← 关键: 退出时自动清理
        Name::new("MySpecial_Object"),
    ));
}
```

### 4.4 LevelEntity — 清理机制

```rust
// 所有关卡生成的实体必须带 LevelEntity 组件
// OnExit(GameLevel::Xxx) → cleanup_level 自动 despawn

#[derive(Component)]
pub struct LevelEntity;

fn cleanup_level(mut commands: Commands, query: Query<Entity, With<LevelEntity>>) {
    for entity in query.iter() {
        commands.entity(entity).despawn();
    }
}
```

### 5.2 选用决策

```
新场景需要相机?
    │
    ├── 有 Player 实体? ──YES──→ 使用 CameraPlugin (游戏层)
    │
    ├── 自由探索/演示? ──YES──→ 使用 CameraControllerPlugin (通用层)
    │                           spawn 相机 + CameraController 组件
    │
    └── 俯视/固定视角? ──→ 手动 spawn Camera3d + Transform
```

### 5.3 CameraController 组件

```rust
#[derive(Component, Reflect)]
pub struct CameraController {
    pub walk_speed: f32,          // 默认 5.0
    pub run_speed: f32,           // 默认 10.0 (Shift)
    pub mouse_sensitivity: f32,   // 默认 0.002
    // pitch / yaw 内部追踪，外部不可见
}

// 使用:
commands.spawn((
    Camera3d::default(),
    CameraController::default(),  // 默认参数
    Transform::from_xyz(0.0, 2.0, 5.0).looking_at(Vec3::ZERO, Vec3::Y),
));

// 自定义速度:
commands.spawn((
    Camera3d::default(),
    CameraController { walk_speed: 10.0, ..default() },
    Transform::from_xyz(0.0, 2.0, 5.0).looking_at(Vec3::ZERO, Vec3::Y),
));
```

### 5.4 多机位扩展 (可复用)

```rust
// 在任意模块中复制此代码即可
#[derive(Resource)]
struct FixedViewpoints {
    points: Vec<(Vec3, Vec3)>,  // (位置, 注视点)
    current: usize,
}

fn cycle_viewpoint(
    keys: Res<ButtonInput<KeyCode>>,
    mut vp: ResMut<FixedViewpoints>,
    mut cam_q: Query<&mut Transform, With<Camera3d>>,
) {
    if !keys.just_pressed(KeyCode::KeyV) { return; }
    let Ok(mut t) = cam_q.single_mut() else { return };
    let (pos, look_at) = vp.points[vp.current];
    t.translation = pos;
    t.look_at(look_at, Vec3::Y);
    vp.current = (vp.current + 1) % vp.points.len();
}
```

## 六、模块间依赖规范

```
main.rs
 ├──log::configured_plugins()  ← 基础插件 (DefaultPlugins + 窗口设置)
 │
 ├── SolariPlugins             ← 光追渲染 (常驻, 不影响 PBR)
 ├── CameraControllerPlugin    ← 通用相机 (常驻, query 空则无效果)
 │
 ├── game_state::GameStatePlugin  ← 状态机 (最先)
 ├── level::LevelPlugin           ← 关卡 (依赖 GameState)
 ├── player::PlayerPlugin         ← 玩家 (依赖 GameState)
 ├── camera::CameraPlugin         ← 游戏相机 (依赖 Player + GameState)
 └── 其他插件...                  ← 功能模块

依赖规则:
  · 上层可依赖下层, 下层不依赖上层
  · 模块间用 Message 通信, 不直接 import 对方函数
  · 公共类型(Component/Resource/Event)从定义模块 re-export
```

### 消息通信示例

```rust
// ❌ 直接调用 (紧耦合)
fn system_a(mut player_q: Query<&mut Health, With<Player>>) {
    player_q.single_mut().0 -= 10;
}

// ✅ 消息通信 (松耦合)
fn system_a(mut writer: MessageWriter<DamagePlayerEvent>) {
    writer.write(DamagePlayerEvent(10));
}
fn system_b(mut events: MessageReader<DamagePlayerEvent>, mut player_q: ...) {
    for ev in events.read() { /* 处理 */ }
}
```

| 调玩家移动速度 | 改 `src/config.rs` 或 `src/player.rs` 中的 `move_speed` |
| 调鼠标灵敏度 | 改 `src/player.rs` 中的 `mouse_sensitivity` |
| 加一个新关卡 | 按 [四、关卡代码复用设计](#四关卡代码复用设计) 三步走 |
| 改 NPC 对话 | 编辑 `assets/dialogues/<对话id>.ron` |
| 调光照亮度 | 改 `src/world.rs` 中的 `ambient.brightness` |
| 加一个新功能 | 按 [七、新增功能检查清单](#七新增功能检查清单) 逐项确认 |
| 查参数在哪里改 | 看 `docs/游戏参数调优参考手册.md` |
| 学怎么做关卡 | 看 `docs/通用关卡设计制作指南.md` |

### 9.4 开发流水线

```
编辑代码 → cargo check (验证编译) → cargo clippy (检查质量)
         → cargo fmt (格式化) → cargo run (测试)
         → git commit (提交)
```
