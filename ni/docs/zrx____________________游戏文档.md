## 1. 游戏概述与世界观

### 游戏名称
残响回廊

### 背景设定
雨夜收到失踪姐姐来信，前往遗弃疗养院「静默疗养院」。建筑随探索动态重构如活体迷宫，通过场景收集、深度探索、记忆对话拼凑真相，直面心魔，完成救赎或坠入永恒轮回。

### 核心机制
- **收集**：病历卡、钥匙、日记碎片、承载情绪记忆的「回音石」
- **探索**：回字形回廊，解谜触发空间重组，紫外线手电探测隐藏痕迹
- **对话与残响**：固定电话与「管理员」对话，触碰物品触发逝者记忆残响
- **生存潜行**：躲避「残响体」追逐，藏身储物柜/床底，镜子反射定住怪物

### 游戏流程区域

| 区域 | 主题 | 核心玩法 | 关键收集品 |
|---|---|---|---|
| A. 接待大厅 | 遗忘的入口 | 教学、初始探索、基础解谜 | 地图碎片A、访客签名簿 |
| B. 东翼·沉默病区 | 疾病与治疗 | 收集、潜行教学 | 病历卡1-5、吊瓶标签 |
| C. 中央庭院 | 扭曲的自然 | 解谜、核心剧情触发 | 回音石组合、姐姐丝巾 |
| D. 西翼·儿童病区 | 被遗忘的童年 | 深度探索、对话解谜 | 核心病历页1-3、全家福残片 |
| E. 地下层·残响核心 | 真相与终结 | 逃脱、塔防、Boss战、抉择 | 核心病历页4-8 |

## 2. 核心玩法与游戏流程

### 序章：雨夜来信
- **地点**：疗养院大门、接待大厅
- 拾取地图碎片A，前台电话响起，管理员警告。登记表背面姐姐字迹："别信他，来档案室找我。"
- 收集：手电筒、访客签名簿
- 解谜：肖像画眼睛朝向对应挂钟得密码`1924`，解锁东翼铁栅门

### 第一幕：沉默病区
- **地点**：东翼病房、护士站、药房
- 搜集5份病历卡，背面有姐姐红色批注。203病房床下集齐吊瓶标签解锁木箱，获手术刀开信刀与日记碎片①
- 护士站广播触发诡异童谣，电话传来姐姐警告，首次遭遇残响体，躲入护士台储物柜
- 药房获取镇静剂喷雾

### 第二幕：破碎记忆
- **地点**：中央庭院、西翼儿童病区、档案室
- 枯槐树下拾取姐姐丝巾，触发记忆残响。收集3块回音石拼接成钥匙，插入槐树凹槽，喷泉移开露出档案室阶梯
- 播放049号磁带，姐姐揭示需销毁8份「病历核心」打破循环。管理员暴怒，书架移位形成迷宫

### 第三幕前半：回廊深处
- **地点**：地下治疗室、太平间
- 探索三间治疗室，面对记忆幻象完成对话解谜。太平间空棺找到姐姐录影带，放入儿时项链获取剩余核心病历页
- 8份核心集齐后合成「静默疗养院真相档案」

### 第三幕中段：档案室塔防
- 主线高潮，回音石搭建防御阵列，抵御8波残响围攻。详见第9、10章节

### 第三幕后半：庭院最终Boss战
- 回音石布置8个碑座，利用镜子反射引导管理员撞击自身幻象，重复8次终结循环

### 结局分支
- **结局A（完美）**：善意对话、全收集，姐姐消散，主角放下愧疚
- **结局B（轮回）**：关键对话缺失、收集不全，取代管理员成为新守夜人

### 完整流程
```
序章 → 第一幕 → 第二幕 → 第三幕前半 → 第三幕中段(塔防) → 第三幕后半(Boss) → 结局A/B → 解锁无尽模式
```

## 4. 美术核心设计概念：年代与材质

### 年代定位
1983年故事时间，疗养院1976年废弃。建筑1940年代建造，装修保留1950-60年代医疗美学。关键词：**潮湿的腐烂**。

### 废弃核心原则
「突然废弃、无人触碰7年」——漆面局部剥落、玻璃积灰但完整、纺织品形态完好、纸张字迹清晰、金属仅表层锈蚀，保留生前生活痕迹。

### 六种核心材质

**材质一：油漆剥落金属**
- 基材：铸铁、锻铁、冲压钢板
- 表面：白/淡绿/淡蓝医疗烤漆
- 老化：边缘剥落→红棕色锈层→锈蚀凹坑
- 粗糙度：漆面0.4-0.5，锈面0.8-0.9
- 适用：病床架、手术台底座、输液架、窗框、门把手、储物柜、灯罩

**材质二：釉面瓷砖与医疗陶瓷**
- 基材：白色釉面陶瓷砖、搪瓷
- 老化：釉面开片→污渍渗入→脱釉露陶胎→砖缝发黑
- 粗糙度：完整0.1-0.2，开片0.3-0.4，脱落0.6-0.7
- 适用：墙体下半部、手术室、太平间、药房台面

**材质三：陈年木材**
- 基材：橡木、榆木
- 表面：深色清漆/虫胶漆
- 老化：漆面龟裂→边角磨损露原木→受潮变形→局部发霉发黑
- 粗糙度：漆面0.3-0.4，磨损处0.6-0.7
- 适用：床头柜、座椅、办公桌、相框

**材质四：医疗纺织品**
- 基材：棉布、亚麻、薄毛毯
- 老化：泛黄→污渍渗透→纤维变薄→撕裂露填充物
- 色调：白→米色→浅褐色；血迹均为暗褐色，无鲜艳红色
- 粗糙度：洁净0.7-0.8，污渍0.5-0.6
- 适用：床单、被褥、枕头、病号服、束缚带

**材质五：医学玻璃与橡胶**
- 基材：硼硅玻璃、天然橡胶
- 老化：玻璃积灰雾化、透明度下降；橡胶硬化开裂失弹
- 粗糙度：洁净玻璃0.05，积灰0.2-0.3，老化橡胶0.7-0.8
- 适用：吊瓶、注射器、药瓶、试管、点滴软管

**材质六：纸张与纸板**
- 基材：廉价木浆纸、卡纸、马尼拉纸
- 老化：泛黄→边缘脆化卷曲→水渍晕染→墨迹褪色晕开
- 粗糙度：0.8-0.9，均匀哑光
- 适用：病历卡、日记碎片、签名簿、医学海报

## 5. 地图与关卡设计

### 整体布局
U型二层建筑，五大区域线性串联，内部非线性箱庭，银河恶魔城式设计。解锁能力后可回溯前期区域开启隐藏路径。

### 标准病房空间外壳
- 尺寸：5m × 5m × 4m
- 墙体厚度：0.2m
- 门位：南墙正中，1.2m×2.2m
- 窗位：北墙正中，1.5m×1.2m
- 面数：≤2400三角面

### 单人病房207（案例）
东翼·沉默病区，患者「埃琳娜」因产后抑郁入院，以碎玻璃自尽。
- 收集品：床头柜抽屉（病历卡3/8）、病床下（照片碎片）
- 惊吓事件：离开时房门自动缓慢闭合，走廊灯光变暗红
- 躲藏点：病床下方

## 6. 核心资产建模文档

### 6.1 残响体（核心怪物）
- 概念：历代病患怨念聚合的超自然畸形实体
- 身高：2.1m
- 头部：多层污渍绷带缠绕，嘴部深邃空腔，头顶凸起生锈手术缝合针
- 胸腔：肋骨外翻张开，内部悬浮暗红脉动「痛苦核心」
- 右臂过长垂膝，指尖退化为手术刀片；左臂蜷缩握烧焦病历板；双腿长短不一，外露金属骨科支架
- 面数：40,000-60,000
- 动画：拖行抽搐巡逻、察觉锁定、瞬移追逐、手术刀横扫、定身硬直、待机抽搐

### 6.2 老式储物柜（核心躲藏点）
- 概念：核心避险点位，调控恐怖节奏
- 尺寸：高2.2m，宽0.8m，深0.7m
- 外观：双开门，右门变形留2-3cm缝隙；百叶窗锈堵；浅绿漆面剥落。内部铁皮布满刻字，挂破烂病号服，木地板吱呀作响
- 面数：8,000-12,000
- 玩法：受限第一人称，可屏息降噪，关门声15米内可被探测

### 6.3 第一人称手部
- 概念：玩家化身，传递脆弱与恐惧
- 特征：25-30岁女性冷白皮手，指腹薄茧、中指笔茧，左手银戒指，手背陈旧小疤痕
- 面数：5,000-8,000
- 骨骼：单只手20-25根，肉垫细分骨骼，支持颤抖
- 动画：待机持手电、道具检视、推门、开柜、拾取、注射器使用、屏息握拳、恐惧颤抖

### 6.4 电话与录音机
- **壁挂式电话**：黑色胶木，编织听筒线破损，拨号盘字迹磨损，响铃时机身剧烈震动。面数3,000-5,000
- **磁带录音机**：深灰砖头机，喇叭格栅积灰，透明仓盖发黄开裂，按键卡顿需用力按压。面数4,000-6,000

### 6.5 病历卡与回音石
- **病历卡**：A5卡纸，泛黄卷曲，正面诊疗记录，背面姐姐红字批注，迸溅状暗褐血迹。面数200
- **回音石**：掌心大小不规则多面体，深灰半透明，内部彩色光晕（蓝=悲伤、红=愤怒、绿=恐惧、紫=疯狂），靠近怪物脉动加快。面数600-800

### 6.6 手术台
- 概念：承载痛苦与酷刑记忆的核心资产
- 尺寸：长2.0m，宽0.6m，高0.8m（可调0.7-1.1m）
- 外观：黑色真皮台面硬化开裂，人形血污印痕；4组厚牛皮束缚带配铁质针扣；铸铁防滑底座局部锈蚀
- 面数：8,000-12,000
- 变体：东翼废弃态、地下使用态、最终回廊噩梦态

### 6.7 铁架病床
- 概念：复用率最高资产，兼具「休憩」与「束缚」双重属性
- 尺寸：长2.0m，宽0.9m，床面高0.6m，床头高1.1m
- 外观：漆面剥落露锈，床头指甲抓痕；4-6个束缚带固定点；床下0.4m低位躲藏点
- 被褥状态：整齐叠放、凌乱掀开、人形隆起、被褥消失
- 变体：整洁无人、挣扎痕迹、废弃腐烂
- 面数：4,000-6,000

### 6.8 散落小物品
- **金属**：手术剪(500面)、止血钳、玻璃注射器(600面)、药瓶(400面)
- **纺织品**：抹布(300面)、绷带卷、散落束缚带
- **纸张**：散落病历页(100面)、医学挂图、旧报纸
- **玻璃陶瓷**：水杯(300面)、搪瓷便盆(500面)
- **有机**：头发团(200面)、飞蛾尸体(200面)

### 建模优先级
1. **最高**：躲藏点（柜子/床底）、核心收集品（病历卡/回音石）
2. **次高**：残响体、电话/录音机
3. **基础**：模块化场景、第一人称手部

## 9. 塔防模式：玩法融合、数值与攻击方式

### 核心机制：残响回溯
部署回音石阵列，怪物造成高额伤害时手动激活，回溯区域时间3-5秒。代价：120秒冷却，区域恐惧值飙升，怪物强度小幅提升。

### 经济数值
- 初始金币：200
- 工资：2金币/秒
- 小怪：5-10金币，精英：25-50金币，Boss：150-300金币

### 怪物数值

| 怪物 | HP | ATK | MSPD | 特殊 |
|---|---|---|---|---|
| 残响碎片 | 30 | 5 | 1.5格/秒 | 无 |
| 残响体(普通) | 80 | 15 | 1.0格/秒 | 对门双倍伤害 |
| 残响体(精英) | 200 | 25 | 0.7格/秒 | 范围恐惧光环 |
| 记忆撕裂者 | 500 | 40 | 0.5格/秒 | 死后自爆 |
| 管理员化身 | 1500 | 60 | 0.4格/秒 | 时间加速 |

### 防御塔

| 塔名 | 世界观名 | 成本 | ATK | ASPD | RNG | 攻击方式 |
|---|---|---|---|---|---|---|
| 哀鸣炮台 | 悲鸣回响 | 50 | 15 | 1.0 | 3格 | 声波弹+30%溅射 |
| 凝视之眼 | 监察之瞳 | 40 | 0 | 持续 | 4格 | 减速40%+易伤20% |
| 记忆尖刺 | 痛苦结晶 | 100 | 25 | 0.5 | 2.5格扇形 | AOE+击退 |

### 伤害公式
```
实际伤害 = ATK × (1 - 目标减伤率) × (1 + 易伤加成)
```

### 平衡指标
- 单基础塔处理3-4只同级杂兵
- 精英需2-3座基础塔集火
- 每波怪物总HP为塔总DPS的1.5-2倍

## 11. 残响回溯机制：数据存储结构与落地规范

### 核心思路
记录受影响对象在关键时间点的状态快照，回溯触发时根据快照精准恢复。以下使用 RON 格式展示，同时适用于JSON等通用格式。

### 需记录的实体与状态

| 对象类型 | 记录字段 |
|---|---|
| 可破坏物（门、建筑） | 位置ID、当前HP、是否损毁 |
| 敌人/怪物 | 位置、朝向、HP、Buff/Debuff剩余时间与层数、AI行为状态 |
| 玩家 | 位置、金币、道具冷却状态 |

### 数据结构（RON格式）
```ron
TimeSnapshot(
    timestamp: 12.5,
    affected_objects: {
        doors: {
            "ward_207_entrance": DoorState(
                pos_id: "door_ward_207", hp: 80, is_broken: false
            ),
            "archives_main_gate": DoorState(
                pos_id: "door_archives_main", hp: 0, is_broken: true
            ),
        },
        buildings: {
            "tower_echo_cannon_01": BuildingState(
                pos_id: "build_echo_01", hp: 120, is_active: true, cooldown_remaining: 0.0
            ),
        },
        enemies: {
            "echo_remnant_04": EnemyState(
                enemy_id: "echo_04", position: (x: 12.3, y: 0.0, z: 4.5),
                rotation: 0.78, hp: 65,
                active_buffs: [Buff(id: "fear_slow", remaining_time: 2.1, stacks: 1)],
                current_ai_state: "Chasing"
            ),
            "admin_avatar": EnemyState(
                enemy_id: "boss_admin", position: (x: 25.0, y: 0.0, z: 18.2),
                rotation: 2.35, hp: 1200, active_buffs: [],
                current_ai_state: "CastingSkill"
            ),
        },
        player: PlayerState(
            position: (x: 15.0, y: 1.6, z: 8.0), gold: 340,
            item_cooldowns: { "echo_stone_array": 45.0, "sedative_spray": 0.0 }
        ),
    },
)
```

### 设计要点
- 每个对象用唯一ID标识，恢复时查找ID直接覆盖属性
- `timestamp` 用于多快照管理和过期判断
- Buff列表完整记录，回溯时移除新增Buff、恢复原有剩余时间
- 玩家金币回溯会丢失回溯期间新增的金币

### 运行时实现
1. **环形缓冲区**：每个回音石阵列维护定长缓冲（存储10秒，每秒2次采样），回溯时取出对应快照
2. **恢复流程**：遍历快照对象→存在则覆盖属性→已销毁则重建→移除时间点后的Buff→触发回溯特效音效
3. **性能优化**：仅记录动态状态，大量敌人时空间哈希，回溯冷却期停止记录
