# 菜单系统实现方案

## 一、当前状态

- **主菜单**：只有"开始游戏"、"多人聊天"、"退出"三个按钮，无设置入口
- **暂停菜单**：只有"继续游戏"、"返回主菜单"
- **HUD**：关卡名、生命值、分数、收集品计数
- **无任何设置功能**：视频/音频/语言/控制全部缺失
- **无设置持久化**：每次启动恢复默认
- **音频**：仅背景音乐播放，无音量控制、无音效分离
- **所有文本硬编码**：无本地化系统

### 3.3 持久化

```rust
/// 完整的设置持久化结构
#[derive(Resource, Serialize, Deserialize)]
struct SettingsSaveData {
    video: VideoSettings,
    audio: AudioSettings,
    locale: LocaleSettings,
    controls: ControlSettings,
}

// 存储路径: <user_data>/settings.ron
// Windows: %APPDATA%/ni/settings.ron

fn save_settings(data: Res<SettingsSaveData>) {
    let path = get_settings_path();
    let ron = ron::ser::to_string_pretty(&*data, Default::default()).unwrap();
    std::fs::write(path, ron).ok();
}

fn load_settings() -> Option<SettingsSaveData> {
    let path = get_settings_path();
    let ron = std::fs::read_to_string(path).ok()?;
    ron::de::from_str(&ron).ok()
}
```

### 3.4 系统执行顺序

```
First (启动时):
  load_settings_system        — 从文件加载设置，没有则用默认值
  apply_video_settings        — 根据 VideoSettings 设置窗口/画质
  apply_audio_settings        — 根据 AudioSettings 设置音量
  apply_control_settings      — 更新鼠标灵敏度等

Update:
  menu_navigation_system      — 处理返回键、页面跳转
  settings_ui_systems         — 各类设置页面的 egui 渲染
  keybind_capture_system      — 处理按键重绑定（捕获输入）

PostUpdate:
  detect_settings_change      — 设置变更时自动保存
  apply_pending_video         — 延迟应用视频变更（防抖）
```

## 四、核心技术实现

### 4.1 视频设置应用

```rust
fn apply_video_settings(
    settings: Res<VideoSettings>,
    mut windows: Query<&mut Window>,
    // Bevy 0.18 窗口 API
) {
    let mut window = windows.single_mut();
    window.resolution.set(settings.resolution.width, settings.resolution.height);
    window.mode = match settings.window_mode {
        WindowMode::Fullscreen => bevy::window::WindowMode::Fullscreen(MonitorSelection::Primary),
        WindowMode::BorderlessWindow => bevy::window::WindowMode::BorderlessFullscreen(MonitorSelection::Primary),
        WindowMode::Windowed => bevy::window::WindowMode::Windowed,
    };
    window.present_mode = if settings.vsync {
        bevy::window::PresentMode::AutoVsync
    } else {
        bevy::window::PresentMode::AutoNoVsync
    };
}
```

**画质切换**需要分两步：
1. 预设（低/中/高）触发预定义配置表
2. 自定义模式允许逐项调整

**分辨率枚举**从 `Window::available_monitors()` + `Window::available_video_modes()` 动态获取，在下拉列表中只展示当前显示器的可选分辨率。

### 4.2 音频设置应用

当前项目只有背景音乐（`music.wav`），需要：

1. **分类音量**：给音频实体打标记组件
   ```rust
   #[derive(Component)]
   enum AudioCategory { Music, Sfx, Ambient }
   ```

2. **音量应用系统**：
   ```rust
   fn apply_audio_settings(
       settings: Res<AudioSettings>,
       mut audio_q: Query<(&AudioCategory, &mut AudioSink)>,
   ) {
       for (category, mut sink) in &mut audio_q {
           let volume = match category {
               AudioCategory::Music => settings.music_volume,
               AudioCategory::Sfx => settings.sfx_volume,
               AudioCategory::Ambient => settings.ambient_volume,
           };
           let final_volume = if settings.muted { 0.0 } else { volume * settings.master_volume };
           sink.set_volume(final_volume);
       }
   }
   ```

3. **预览按钮**：每个音效滑块旁放一个播放按钮，拖动滑块后点击试听

### 4.3 语言/本地化系统


### 4.4 按键重绑定

这是技术上最复杂的部分。实现方式：

```rust
fn keybind_capture_system(
    mut contexts: EguiContexts,
    mut pending_capture: Local<Option<&'static str>>, // 正在等待绑定的 action 名
    keys: Res<ButtonInput<KeyCode>>,
    mut control_settings: ResMut<ControlSettings>,
) {
    let Some(action_name) = *pending_capture else { return };

    // 检测第一个按下的键
    for key in keys.get_just_pressed() {
        // 跳过特殊键（鼠标按键、修饰键需要特殊处理）
        if matches!(key, KeyCode::Escape) {
            // Esc 取消捕获
            *pending_capture = None;
            return;
        }

        // 将新按键绑定到 action
        control_settings.keybinds.set(action_name, *key);
        *pending_capture = None;
        return;
    }
}
```

egui 端实现：
1. 每个按键绑定显示为一个按钮，文本为 `KeyCode` 的可读名称
2. 点击按钮后进入"等待按键"状态（按钮文字变为"按下一个键..."闪烁）
3. `keybind_capture_system` 捕获下一个按键并写入配置
4. 检测按键冲突（同一个键绑定了多个动作）时显示警告标记

## 七、实施优先级

| 优先级 | 功能 | 工作量 | 理由 |
|--------|------|--------|------|
| **P0** | 设置框架（SettingsPlugin + 持久化） | 中 | 所有设置功能的基础 |
| **P0** | 主菜单/暂停菜单新增"设置"按钮 | 小 | 入口，联动现有菜单 |
| **P1** | 视频设置（分辨率/全屏/VSync/FOV） | 中 | 最核心的玩家需求 |
| **P1** | 音频设置（主音量/音乐/音效） | 中 | 需要改造现有音频系统 |

| **P3** | 设置预览/试听功能 | 小 | 锦上添花 |

## 九、注意事项

1. **视频模式切换需防抖**：切换全屏/分辨率时加 0.5 秒倒计时确认，防止误操作导致黑屏循环
2. **按键冲突检测**：重绑定时检查是否已有其他动作绑定相同按键，用警告图标提示
3. **Escape 键不可完全移除绑定**：至少保留一个返回/暂停键，防止玩家锁死在设置页面
4. **设置即时预览**：视频/音频设置变更立即生效，不需要点击"应用"按钮；画质预设切换也实时更新
5. **画质预设联动**：选择预设（低/中/高）时，自定义选项跟随变化；一旦手动修改某项自定义选项，预设自动切换为"自定义"
