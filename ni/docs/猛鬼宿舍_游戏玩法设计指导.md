#### 1. 游戏概述与世界观

**游戏名称**：残响回廊

**背景设定**：玩家在一个雨夜收到失踪姐姐寄来的信件，循着信件地址，孤身前往一座上世纪遗弃的疗养院——「静默疗养院」。这座建筑并非固定死寂的废墟，而是一座会随探索行为动态重构、如同活体一般的迷宫。玩家将通过场景收集、深度探索、记忆对话层层拼凑尘封真相，直面自身的心魔与执念，最终完成救赎或坠入永恒轮回。

**核心机制**：
- **收集**：病历卡、场景钥匙、姐姐日记碎片、承载情绪记忆的「回音石」，所有收集品均承担解谜与叙事功能。
- **探索**：整体为回字形连通回廊结构，完成特定解谜可触发空间重组、解锁新区域；紫外线手电可观测肉眼不可见的场景残留痕迹与隐秘线索。
- **对话与残响**：可通过场景老式固定电话与神秘「管理员」远程对话；触碰关键物品可触发逝者记忆残响，以幻听、画面闪回形式还原过往悲剧片段。
- **生存潜行**：场景游荡由病患怨念聚合而成的「残响体」，遭遇追逐时，可潜行躲避、藏身储物柜/病床底，或利用镜子反射短暂定住怪物逃生。

**游戏流程区域**：

| 区域 | 主题 | 核心玩法 | 关键收集品 |
|---|---|---|---|
| A. 接待大厅 | 遗忘的入口 | 新手教学、初始探索、基础解谜 | 地图碎片A、访客签名簿 |
| B. 东翼·沉默病区 | 疾病与治疗 | 道具收集、潜行机制教学 | 病历卡1-5、吊瓶标签 |
| C. 中央庭院 | 扭曲的自然 | 场景解谜、核心剧情触发 | 回音石组合、姐姐丝巾 |
| D. 西翼·儿童病区 | 被遗忘的童年 | 深度探索、剧情对话解谜 | 核心病历页1-3、全家福残片 |
| E. 地下层·残响核心 | 真相与终结 | 极限逃脱、塔防防守、Boss决战、剧情抉择 | 核心病历页4-8、最终抉择道具 |

#### 2. 核心玩法与游戏流程

**序章：雨夜来信**
-   **地点**：疗养院大门、接待大厅
-   玩家雨夜抵达疗养院，在接待大厅拾取地图碎片A，随即前台电话响起，管理员发出警告：“天黑前离开”。前台入院登记表背面留有姐姐手写字迹：“别信他，来档案室找我。”
-   收集道具：手电筒、访客签名簿
-   核心解谜：观察四幅创始人肖像画的眼睛朝向，对应挂钟数字得出密码「1924」，解锁铁栅门，开启东翼病区通路。

**第一幕：沉默病区（收集+潜行主导）**
-   **地点**：东翼病房、护士站、药房
-   玩家需搜集5份病历卡，每份卡片背面均留有姐姐的红色批注，暗藏剧情线索。在203病房床下可找到上锁木箱，集齐场景内三个吊瓶标签即可解锁，获得手术刀开信刀与姐姐日记碎片①。
-   探索护士站时，广播自动播放诡异小女孩歌声，随即电话响起，传来姐姐的紧急警告，玩家首次遭遇残响体，需快速躲入护士台下储物柜避险。同时可在药房获取关键道具镇静剂喷雾。

**第二幕：破碎记忆（对话与循环探索）**
-   **地点**：中央庭院、西翼儿童病区、地下档案室
-   玩家在中央庭院枯槐树下拾取姐姐丝巾，触发大范围记忆残响。收集3块零散回音石拼接成钥匙，插入槐树凹槽触发机关，喷泉移位露出地下档案室阶梯。
-   进入档案室播放049号磁带，姐姐的录音揭示核心真相：需销毁8份「病历核心」，打破疗养院无尽记忆循环。录音结束后管理员暴怒，书架整体移位形成迷宫，玩家需在迷宫中搜寻万能钥匙与多份核心病历页。

**第三幕前半：回廊深处（极限逃脱）**
-   **地点**：地下治疗室、太平间
-   玩家深入地下扭曲回廊，探索三间隐秘治疗室，直面对应记忆幻象并完成对话解谜。在太平间空棺中找到姐姐录影带，放入随身儿时项链作为信物，获取剩余核心病历页。集齐8份核心病历后，自动合成「静默疗养院真相档案」。

**第三幕中段：档案室塔防（8波防御战）**
-   主线核心高潮玩法，承接收集结局、铺垫最终Boss战。玩家借助回音石搭建防御阵列，抵御8波残响怪物围攻，守住档案室核心区域即可成功推进终章剧情。

**第三幕后半：庭院最终Boss战**
-   塔防防守成功后，玩家携带完整真相档案返回中央庭院，管理员具象化为巨型残响集合体。玩家将回音石布置于庭院8个碑座，利用镜子反射机制，引导管理员撞击自身幻象，重复8次击碎怨念核心，终结循环。

**结局分支**：
-   **结局A（完美结局）**：全程完成善意对话选择、集齐所有关键道具，玩家从废墟中醒来，姐姐彻底消散，主角放下愧疚，完成自我救赎。
-   **结局B（轮回结局）**：缺失关键剧情对话、未完成完整收集，玩家取代管理员，成为全新的回廊守夜人，坠入无尽轮回。

**通关后解锁内容**：通关任意结局，解锁无尽挑战模式——残响深渊（无尽塔防模式）。

#### 3. 核心机制功能测试计划

串联所有独立玩法模块，重点测试无引导状态下的探索合理性、潜行逃脱流畅度、单幕剧情与玩法节奏适配性，修复模块衔接断层、触发异常等问题。

**第四阶段：可玩性平衡与优化调整**

#### 4. 美术核心设计概念：年代与材质

**年代定位**：故事发生于1983年，静默疗养院1976年废弃关闭；建筑始建于1940年代，室内装修、设施样式保留1950-1960年代医疗美学风格。核心美术关键词：**潮湿的腐烂**。

**废弃核心原则**：场景物品为「突然废弃、无人触碰7年」状态，非百年废墟。漆面局部剥落、玻璃积灰完整、纺织品形态完好、纸张字迹清晰、金属仅表层锈蚀，保留大量生前生活痕迹。

**六种核心材质定义**：

**材质一：油漆剥落金属**
-   **基材**：铸铁、锻铁、冲压钢板
-   **表面处理**：白色、淡绿色、淡蓝色医疗烤漆
-   **老化方式**：边缘棱角剥落→露出红棕色锈层→锈蚀蔓延形成凹坑
-   **粗糙度**：漆面0.4-0.5，锈面0.8-0.9
-   **适用物品**：病床架、手术台底座、输液架、窗框、门把手、储物柜外壳、灯罩

**材质二：釉面瓷砖与医疗陶瓷**
-   **基材**：白色釉面陶瓷砖、医疗搪瓷
-   **表面处理**：高光釉面，20cm×10cm标准医疗瓷砖
-   **老化方式**：釉面开片→污渍渗入裂纹→局部脱釉露陶胎→砖缝发黑积垢
-   **粗糙度**：完整釉面0.1-0.2，开片区域0.3-0.4，脱落区域0.6-0.7
-   **适用物品**：墙体下半部、手术室、太平间、药房台面

**材质三：陈年木材**
-   **基材**：橡木、榆木实木
-   **表面处理**：深色清漆、虫胶漆封层
-   **老化方式**：漆面龟裂→边角磨损露原木→受潮变形→局部发霉发黑
-   **粗糙度**：漆面0.3-0.4，磨损处0.6-0.7
-   **适用物品**：床头柜、座椅、办公桌、装饰相框

**材质四：医疗纺织品**
-   **基材**：棉布、亚麻、薄毛毯
-   **表面处理**：纯白、蓝白条纹制式布料，经多次工业洗涤
-   **老化方式**：整体泛黄→污渍渗透→纤维变薄磨损→局部撕裂露填充物
-   **色调规范**：白→米色→浅褐色渐变；血迹为暗褐色陈旧痕迹，无鲜艳红色
-   **粗糙度**：洁净处0.7-0.8，污渍处0.5-0.6
-   **适用物品**：床单、被褥、枕头、病号服、束缚带

**材质五：医学玻璃与橡胶**
-   **基材**：硼硅玻璃、天然橡胶
-   **老化方式**：玻璃积灰雾化、透明度下降；橡胶硬化、开裂失弹
-   **粗糙度**：洁净玻璃0.05，积灰玻璃0.2-0.3，老化橡胶0.7-0.8
-   **适用物品**：吊瓶、注射器、药瓶、试管、点滴软管

**材质六：纸张与纸板**
-   **基材**：廉价木浆纸、卡纸、马尼拉纸
-   **老化方式**：整体泛黄→边缘脆化卷曲→水渍晕染成地图纹路→墨迹褪色晕开
-   **粗糙度**：0.8-0.9，均匀哑光质感
-   **适用物品**：病历卡、日记碎片、访客签名簿、医学海报

#### 5. 地图与关卡设计

**整体布局**：疗养院为U型二层建筑，五大区域线性串联，单区域内部为非线性箱庭结构，采用银河恶魔城式设计。玩家解锁新道具、新能力后，可回溯前期区域开启隐藏路径与彩蛋内容。

**标准病房空间外壳（通用模块化单元）**：
-   房间尺寸：5m × 5m × 4m
-   墙体厚度：0.2m
-   门位：南墙正中，尺寸1.2m×2.2m
-   窗位：北墙正中，尺寸1.5m×1.2m
-   模型面数：单房间总三角面≤2400，保障运行流畅度

**单人病房详细设计（病房207·案例）**：
-   隶属于东翼沉默病区，位于走廊中段偏左。为病患「埃琳娜」的专属病房，患者因重度产后抑郁症入院，最终以碎玻璃自尽，房间留存强烈怨念痕迹。
-   核心收集品：床头柜抽屉（病历卡3/8）、病床下方（照片碎片）
-   专属惊吓事件：玩家准备离开时房门自动缓慢闭合，走廊灯光转为暗红色，氛围骤变
-   躲藏点位：病床下方可进入避险

#### 6. 核心资产建模文档

**6.1 残响体（核心怪物）**
-   **核心概念**：疗养院历代病患怨念聚合而成的超自然畸形实体，是游戏核心追逐怪物。
-   **身高**：约2.1m
-   **外观细节**：头部被多层污渍绷带完全缠绕，嘴部形成深邃空腔；头顶凸起多根生锈大号手术缝合针。胸腔为视觉核心，肋骨外翻张开形成空腔，内部悬浮低频脉动暗红色「痛苦核心」。四肢不对称畸形，右臂过长垂过膝盖，指尖退化为手术刀片；左臂蜷缩于胸前，紧握烧焦病历板；双腿长短不一，单腿搭载外露金属骨科支架。
-   **三角面数**：40000-60000
-   **核心动画**：拖行抽搐巡逻、玩家锁定察觉、瞬移式快速追逐、手术刀横扫攻击、镜子定身硬直、待机无意识抽搐

**6.2 老式储物柜（核心躲藏点）**
-   **核心概念**：玩家核心避险点位，调控恐怖节奏、强化紧张体验的关键资产。
-   **尺寸**：高2.2m，宽0.8m，深0.7m
-   **外观细节**：双开门结构，右门轻微变形无法闭合，留存2-3cm可视缝隙；百叶通风口锈死堵塞；表层浅绿色医疗漆面斑驳剥落。内部铁皮内壁布满绝望刻字，悬挂破烂条纹病号服，木质地面踩踏吱呀作响。
-   **三角面数**：8000-12000
-   **玩法功能**：进入后切换受限第一人称视角，可屏息降噪；关门声响可被15米内残响体探测。

**6.3 第一人称手部（主角化身）**
-   **核心概念**：玩家沉浸式化身，传递角色脆弱、恐惧与挣扎感。
-   **外观特征**：25-30岁女性冷白皮手部，指腹薄茧、中指笔茧，左手无名指佩戴银戒指，手背带有细小陈旧疤痕。
-   **三角面数**：5000-8000
-   **骨骼配置**：单只手20-25根骨骼，含肉垫细分骨骼，支持细微颤抖动态。
-   **核心动画**：待机持手电、道具检视、推门、开合柜门、拾取物品、使用注射器、屏息握拳、恐惧颤抖

**6.4 电话与录音机（核心交互资产）**
-   **壁挂式老式电话**：黑色胶木机身，听筒编织线破损老化，旋转拨号盘字迹磨损，来电响铃时机身剧烈震动。三角面：3000-5000。
-   **台式磁带录音机**：复古深灰色砖头机型，喇叭格栅积灰堵塞，透明仓盖发黄开裂，按键老化卡顿，按压有厚重反馈。三角面：4000-6000。
-   **核心交互**：听筒拿起/挂断、磁带放入取出、按键播放，全程仪式感动作反馈。

**6.5 病历卡与回音石（核心收集品）**
-   **病历卡**：A5卡纸，整体泛黄卷曲，正面为制式诊疗记录，背面留有姐姐红色手写批注，表面分布自然迸溅状暗褐色血迹。三角面：200。
-   **回音石**：掌心大小不规则多面体，深灰色半透明质感；内部悬浮对应情绪的彩色光晕（蓝=悲伤、红=愤怒、绿=恐惧、紫=疯狂），靠近怪物时光晕脉动频率加快。三角面：600-800。

**6.6 手术台**
-   **核心概念**：承载疗养院痛苦与酷刑记忆的核心场景资产。
-   **尺寸**：长2.0m，宽0.6m，高0.8m（支持0.7-1.1m高度调节）
-   **外观细节**：黑色真皮台面硬化开裂，留存人形血污印痕；配备4组厚牛皮束缚带与铁质针扣；铸铁防滑底座局部锈蚀。
-   **三角面数**：8000-12000
-   **状态变体**：东翼废弃状态、地下治疗室使用状态、最终回廊噩梦异化状态

**6.7 铁架病床**

#### 11. 残响回溯机制：数据存储结构与落地规范

**核心设计思路**：为「残响回溯」机制设计数据存储结构，核心原则是记录每个受影响对象在关键时间点的状态快照，并在回溯触发时根据快照精准恢复。以下使用 **RON格式**（Rusty Object Notation）展示数据结构，同时适用于JSON等通用格式。

**需要记录的实体与状态**：

| 对象类型 | 需要记录的状态字段 |
|---|---|
| 可破坏物（门、建筑） | 位置ID、当前HP、是否已损毁 |
| 敌人/怪物 | 位置、朝向、当前HP、身上所有Buff/Debuff的剩余时间与层数、AI行为状态 |
| 玩家/幸存者 | 位置、金币数量、携带道具冷却状态 |

**数据结构示例（RON格式）**：
```ron
TimeSnapshot(
    timestamp: 12.5,
    affected_objects: {
        doors: {
            "ward_207_entrance": DoorState(
                pos_id: "door_ward_207",
                hp: 80,
                is_broken: false
            ),
            "archives_main_gate": DoorState(
                pos_id: "door_archives_main",
                hp: 0,
                is_broken: true
            ),
        },
        buildings: {
            "tower_echo_cannon_01": BuildingState(
                pos_id: "build_echo_01",
                hp: 120,
                is_active: true,
                cooldown_remaining: 0.0
            ),
        },
        enemies: {
            "echo_remnant_04": EnemyState(
                enemy_id: "echo_04",
                position: (x: 12.3, y: 0.0, z: 4.5),
                rotation: 0.78,
                hp: 65,
                active_buffs: [
                    Buff(id: "fear_slow", remaining_time: 2.1, stacks: 1),
                ],
                current_ai_state: "Chasing"
            ),
            "admin_avatar": EnemyState(
                enemy_id: "boss_admin",
                position: (x: 25.0, y: 0.0, z: 18.2),
                rotation: 2.35,
                hp: 1200,
                active_buffs: [],
                current_ai_state: "CastingSkill"
            ),
        },
        player: PlayerState(
            position: (x: 15.0, y: 1.6, z: 8.0),
            gold: 340,
            item_cooldowns: {
                "echo_stone_array": 45.0,
                "sedative_spray": 0.0,
            }
        ),
    },
)
```

**设计要点**：
-   每个状态对象用唯一ID标识，恢复时通过ID查找对应实体直接覆盖属性。
-   `timestamp` 用于多快照管理，也可判断快照是否过期。
-   Buff列表完整记录，回溯时会移除回溯后添加的Buff，并恢复原有Buff的剩余时间。
-   玩家金币回溯会丢失回溯期间新增的金币，快照中保存的是回溯生效时刻的金币数。

**存储与运行时实现思路**：
1.  **环形缓冲区存储快照**：每个回音石阵列独立维护定长环形缓冲区（存储最近10秒快照，每秒2次采样）。回溯触发时，根据回溯时间从缓冲区取出对应快照。
2.  **状态恢复流程**：取出快照后遍历所有对象，若对象当前存在则覆盖属性；若已销毁则重新生成并恢复状态。玩家自身状态同样覆盖。移除所有在当前时间点之后添加的Buff/状态效果。触发回溯特效和音效。
3.  **性能优化**：快照仅记录动态状态，不记录静态数据。大量敌人时对敌人状态做空间哈希，只存储受影响房间区域。回溯冷却期间停止记录快照以节省性能。
