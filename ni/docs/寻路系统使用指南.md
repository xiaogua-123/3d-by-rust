# 寻路系统使用指南

## 概述

A* 寻路系统提供 NPC 自动寻路能力。通过组件驱动：给实体挂载 `Navigator` + `NavTarget`，系统自动处理路径计算和移动。

**文件结构：**

```
src/pathfinding/
├── mod.rs          # PathfindingPlugin 注册
├── components.rs   # Navigator、NavTarget、NavPath 组件
├── graph.rs        # NavGraph 导航图构建
├── astar.rs        # A* 核心算法
└── systems.rs      # 三条系统管线
```

## 快速开始

```rust
// 1. 注册插件
app.add_plugins(PathfindingPlugin);

// 2. 构建导航图（在关卡启动时）
let nav_graph = NavGraph::from_grid(0.0, 0.0, 100.0, 5.0);
commands.insert_resource(NavGraphResource { graph: nav_graph });

// 3. 生成 NPC，挂载寻路组件
commands.spawn((
    SceneRoot(npc_scene),
    Transform::from_xyz(10.0, 0.0, 10.0),
    Navigator::new(3.0),           // 速度 3.0
    NavTarget::new(player_pos),     // 目标 = 玩家位置
));

// 4. 如果目标是移动实体，每帧更新 NavTarget
fn update_targets(
    player_q: Query<&Transform, With<Player>>,
    mut npc_q: Query<&mut NavTarget, With<MyNpc>>,
) {
    let Ok(player_t) = player_q.single() else { return };
    for mut target in npc_q.iter_mut() {
        target.position = player_t.translation;
    }
}
```

## 组件说明

### Navigator — 寻路代理

```rust
pub struct Navigator {
    pub speed: f32,              // 移动速度（单位/秒）
    pub threshold: f32,          // 到达路径点的距离阈值（默认 0.5）
    pub recalc_interval: f32,    // 重新寻路间隔秒数（默认 2.0）
    pub rotate_to_face: bool,    // 是否旋转面向移动方向（默认 true）
}
```

构造方式：

| 方法 | 说明 |
|------|------|
| `Navigator::new(3.0)` | 仅设置速度，其他用默认值 |
| `Navigator::with_recalc(3.0, 1.0)` | 设置速度 + 重算间隔 |

### NavTarget — 目标位置

```rust
pub struct NavTarget {
    pub position: Vec3,
}
```

通过设置 `position` 字段来改变目标位置。系统检测到目标变化或计时器触发时会自动重新寻路。

也可通过 `From<Vec3>` 直接赋值：

```rust
nav_target.into()  // Vec3 → NavTarget
```

### NavPath — 当前路径（系统写入，外部只读）

```rust
pub struct NavPath {
    pub waypoints: Vec<Vec3>,    // 路径点列表
    pub index: usize,             // 当前目标点下标
    pub completed: bool,          // 是否到达终点
}
```

- `NavPath::new(waypoints)` — 手动创建路径
- `path.current()` — 返回当前目标点 `Option<Vec3>`
- `path.advance()` — 前进到下一个路径点

## 导航图构建

### 从规则网格构建

适用于竞技场、开放区域等规则地形：

```rust
// 中心 (cx, cz) ± size/2 范围内，按 spacing 间距生成网格
let graph = NavGraph::from_grid(cx, cz, size, spacing);
```

| 参数 | 说明 |
|------|------|
| `cx, cz` | 网格中心坐标 |
| `size` | 网格边长 |
| `spacing` | 节点间距（越小越精细，节点越多） |

节点数量 ≈ `(size / spacing + 1)²`。例如 100 范围、5 间距 → 约 441 节点。

### 从任意位置列表构建

适用于自定义路径点、房间导航等不规则场景：

```rust
let points = [(0.0, 0.0), (10.0, 0.0), (10.0, 10.0), (0.0, 10.0)];
let graph = NavGraph::from_positions(&points, 5.0);  // 5.0 内自动连边
```

### 空间哈希查询

```rust
// O(1) 均摊 — 只检查 3×3 邻域格子
let nearest = graph.nearest_node(x, z);
```

## 系统管线

三条系统按顺序每帧执行：

```
detect_nav_target → compute_path → follow_nav_path
```

1. **detect_nav_target** — 检测 `Navigator + NavTarget` 实体是否需要寻路（无路径 / 已完成 / 计时器触发），发出 `RequestPathEvent`
2. **compute_path** — 处理 `RequestPathEvent`，执行 A* 寻路，结果写入 `NavPath`
3. **follow_nav_path** — 沿 `NavPath.waypoints` 移动实体，到达后 `advance()` 到下一个

## 使用示例

### 压力测试（全 NPC 追踪玩家）

```rust
fn stress_npc_set_target(
    player_q: Query<&Transform, With<Player>>,
    mut npc_q: Query<&mut NavTarget, With<StressNpc>>,
) {
    let Ok(player_t) = player_q.single() else { return };
    for mut target in npc_q.iter_mut() {
        target.position = player_t.translation;
    }
}
```

NPC 每 2 秒（`Navigator::with_recalc` 默认）重新计算一次路径，避免每帧 A* 开销。

### 巡逻 NPC（固定路径）

不需要 NavTarget，手动构建 NavPath 即可：

```rust
commands.spawn((
    Navigator::new(2.0),
    NavPath::new(vec![
        Vec3::new(0.0, 0.0, 0.0),
        Vec3::new(10.0, 0.0, 0.0),
        Vec3::new(10.0, 0.0, 10.0),
    ]),
));
```

## 性能调优

| 场景 | 建议 |
|------|------|
| 大量 NPC（1000+） | `recalc_interval` 设为 2~5 秒，增大 graph spacing |
| 动态目标 | `recalc_interval` 设 0.5~1.0 秒 |
| 静态目标（如采集点） | `recalc_interval` 设 5~10 秒或使用 NavPath 一次计算 |
| 复杂地形 | `from_positions` 手动编辑路径点，避免网格浪费 |
| 超大场景 | 分区域构建多个 NavGraph，只查询当前区域 |

### 网格间距参考

| 场景 | spacing | 节点数（100×100） |
|------|---------|-------------------|
| 精细寻路 | 2.0 | ~2600 |
| 默认 | 5.0 | ~441 |
| 粗略寻路 | 10.0 | ~121 |

## 集成注意事项

- `NavGraphResource` 是全局资源，同一时间只有一个导航图
- 场景切换时需重建 `NavGraphResource`
- `PathfindingPlugin` 必须在 `StressTestPlugin` 之前注册（`main.rs` 中已处理）
- NPC 实体需要同时有 `Navigator`、`NavTarget`、`Transform` 三个组件才能自动寻路
