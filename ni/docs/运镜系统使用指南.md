# 运镜系统使用指南

## 概述

运镜系统提供相机平滑跟随、镜头过渡、震屏、轨道环绕功能。通过组件驱动——将对应组件附加到 Camera3d 实体上即可生效，组件移除后效果自动停止，不干扰现有相机控制逻辑。

**位置：** `src/camera_motion.rs`

**插件注册：** `CameraMotionPlugin` 已在 `main.rs` 中注册。

## 组件说明

### CameraTarget — 平滑跟随

让相机平滑跟随某个实体：

```rust
pub struct CameraTarget {
    pub target: Entity,       // 跟随的目标实体
    pub offset: Vec3,         // 相对目标偏移量
    pub follow_speed: f32,    // 跟随速度（越高越快）
    pub look_at: bool,        // 是否注视目标实体
}
```

示例：

```rust
// 让相机跟随玩家，在头顶上方 5 米处，注视玩家
commands.entity(camera_entity).insert(CameraTarget {
    target: player_entity,
    offset: Vec3::new(0.0, 5.0, -8.0),  // 后上方
    follow_speed: 3.0,
    look_at: true,
});
```

跟随使用指数平滑公式：`t = 1 - exp(-speed * dt)`，速度值推荐 2.0~5.0。

### CameraShake — 震屏效果

```rust
pub struct CameraShake {
    pub intensity: f32,    // 震动强度（0.05=轻，0.3=强震）
    pub decay: f32,        // 衰减速度（0~1，越大衰减越快）
    pub duration: f32,     // 持续时间（秒）
}
```

构造方式：

```rust
// 轻震 0.1 秒
CameraShake::new(0.05, 0.1, 0.5);

// 强震 0.5 秒
CameraShake::new(0.3, 0.5, 0.8);
```

震屏在相机世界空间叠加随机偏移，每帧衰减。强度低于 `0.01` 时自动跳过。

### CameraTransition — 镜头过渡

在两个镜头预设之间平滑过渡：

```rust
pub struct CameraTransition {
    pub from: CameraShot,    // 起始镜头
    pub to: CameraShot,      // 目标镜头
    pub duration: f32,       // 过渡时长（秒）
    pub elapsed: f32,        // 已过时间（系统维护）
    pub easing: Easing,      // 缓动函数
}
```

构造方式：

```rust
// 从指定位置到目标镜头
CameraTransition::new(from_shot, to_shot, 1.0);

// 从相机当前位置到目标镜头
CameraTransition::from_current(to_shot, 1.0, &current_transform);
```

过渡完成后自动移除 `CameraTransition` 组件。

### OrbitCamera — 轨道环绕

```rust
pub struct OrbitCamera {
    pub target: Vec3,         // 环绕中心点
    pub radius: f32,          // 环绕半径
    pub yaw: f32,             // 当前偏航角（弧度）
    pub pitch: f32,           // 当前俯仰角（弧度）
    pub rotate_speed: f32,    // 旋转速度（弧度/秒）
}
```

示例：

```rust
// 绕 (0, 0, 0) 点 10 米半径环绕，6 秒一圈
commands.entity(camera_entity).insert(OrbitCamera {
    target: Vec3::ZERO,
    radius: 10.0,
    yaw: 0.0,
    pitch: 0.3,         // 略微俯视
    rotate_speed: std::f32::consts::TAU / 6.0,  // 360°/6s
});
```

## 镜头预设

系统内置常用镜头预设（`crate::camera_motion::shots`）：

| 函数 | 说明 |
|------|------|
| `shots::arena_overview(size)` | 竞技场全景俯视 |
| `shots::core_closeup(pos)` | 核心/物体特写 |
| `shots::spawn_point_view(pos)` | 生成点巡视 |
| `shots::victory()` | 胜利拉远镜头 |
| `shots::defeat(pos)` | 失败俯拍镜头 |

```rust
use crate::camera_motion::shots;

// 胜利镜头过渡 2 秒
let shot = shots::victory();
commands.entity(camera).insert(
    CameraTransition::from_current(shot, 2.0, &current_transform)
);
```

## 缓动函数

| 函数 | 曲线特性 | 适用场景 |
|------|---------|---------|
| `Easing::Linear` | 匀速 | 震屏恢复、机械运动 |
| `Easing::SmoothStep` | 平滑起止 | 通用镜头过渡 |
| `Easing::EaseOutExp` | 快速启动、缓慢停止 | 镜头推拉、冲刺感 |
| `Easing::EaseInOutQuad` | 缓入缓出 | 俯拍/环绕进入 |

## 系统执行

四个系统在 `Update` 调度中运行，互不依赖顺序：

| 系统 | 功能 |
|------|------|
| `apply_smooth_follow` | 处理所有 `CameraTarget` 组件的平滑跟随 |
| `apply_camera_shake` | 处理所有 `CameraShake` 组件的震屏 |
| `handle_camera_transition` | 处理所有 `CameraTransition` 组件的镜头过渡，完成后自动清理 |
| `orbit_camera` | 处理所有 `OrbitCamera` 组件的轨道环绕 |

## 完整示例

### 过场动画序列

```rust
fn start_cutscene(
    mut commands: Commands,
    camera_q: Query<Entity, With<Camera3d>>,
    transform_q: Query<&Transform, With<Camera3d>>,
) {
    let camera = camera_q.single();
    let current_transform = transform_q.get(camera).unwrap();

    // 第一步：鸟瞰建立镜头
    let overview = shots::arena_overview(100.0);
    commands.entity(camera).insert(
        CameraTransition::from_current(overview, 1.5, current_transform)
    );
}
```

### 受击震屏

```rust
fn on_player_hit(
    mut commands: Commands,
    camera_q: Query<Entity, With<Camera3d>>,
) {
    commands.entity(camera_q.single()).insert(
        CameraShake::new(0.15, 0.3, 0.8)  // 中震 0.3 秒
    );
}
```

### 胜利镜头 + 轨道环绕

```rust
fn on_victory(
    mut commands: Commands,
    camera_q: Query<Entity, With<Camera3d>>,
    transform_q: Query<&Transform, With<Camera3d>>,
) {
    let camera = camera_q.single();
    let t = transform_q.get(camera).unwrap();

    // 先从当前位置过渡到胜利位置
    commands.entity(camera).insert(
        CameraTransition::from_current(shots::victory(), 2.0, t)
    );

    // 过渡完成后自动移除 Transition，此时再插入 Orbit 即可
}
```

## 设计要点

- **非侵入式**：运镜组件叠加在现有相机控制之上，`CameraTarget` 平滑修改 Transform，不影响 `CameraController` 或 `LookState` 的逻辑
- **自清理**：`CameraTransition` 完成后自动移除自身，`CameraShake` 完成后虽然保留组件但不再计算（可通过外部系统移除）
- **可组合**：允许多个运镜组件同时存在（如跟随 + 震屏同时生效）
- **预设可扩展**：直接创建 `CameraShot` 即可自定义镜头位置
