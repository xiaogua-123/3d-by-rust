# 3D 冒险游戏 — 视角运镜与镜头切换方案

## 一、当前状态

- 相机作为玩家子实体，刚性跟随，无平滑/弹簧臂
- 偏航旋转玩家实体，俯仰旋转相机子实体
- Solari 演示关卡有独立的自由飞行相机（CameraControllerPlugin）
- 缺乏：相机碰撞检测、镜头切换、运镜过渡、震屏、对话运镜等

---

## 二、架构设计

### 2.1 核心数据结构

```rust
/// 相机模式
enum CameraMode {
    /// 第三人称跟随（主要游玩模式）
    ThirdPerson,
    /// 第一人称
    FirstPerson,
    /// 自由视角（按住 Alt 环绕观察）
    FreeLook,
    /// 对话特写（自动构图 NPC + 玩家）
    DialogueShot,
    /// 脚本化运镜（过场动画）
    Cinematic,
    /// 瞄准模式（越肩/拉近）
    Aiming,
}

/// 弹簧臂配置
struct SpringArm {
    /// 理想偏移（相对于目标）
    target_offset: Vec3,        // 默认 (0, 2.0, -5.0)
    /// 当前实际偏移（平滑后）
    current_offset: Vec3,
    /// 平滑速度
    smooth_speed: f32,          // 5.0
    /// 碰撞检测半径
    collision_radius: f32,      // 0.3
    /// 最小/最大距离
    min_distance: f32,          // 1.0
    max_distance: f32,          // 10.0
}

/// 相机目标（相机看什么/跟着谁）
struct CameraTarget {
    /// 跟随实体
    follow_entity: Entity,
    /// 注视偏移（相对于目标，如胸部高度）
    look_offset: Vec3,          // (0, 1.5, 0)
}

/// 相机控制器（管理运镜模式）
struct CinematicDirector {
    mode: CameraMode,
    /// 当前过渡状态
    transition: Option<CameraTransition>,
    /// 震屏请求队列
    shake_queue: Vec<CameraShake>,
    /// FOV 基准值和当前值
    base_fov: f32,              // 60°
    current_fov: f32,
}

struct CameraTransition {
    from_offset: Vec3,
    to_offset: Vec3,
    from_fov: f32,
    to_fov: f32,
    elapsed: f32,
    duration: f32,              // 0.3 ~ 1.0 秒
    easing: EasingFunction,
}

struct CameraShake {
    intensity: f32,
    frequency: f32,
    duration: f32,
    elapsed: f32,
}
```

### 2.2 系统执行顺序

```
PreUpdate:
  1. camera_mode_input     — 检测模式切换输入（V键/F5等）
  2. camera_target_update  — 更新跟随目标（玩家/对话NPC/脚本路径点）

Update:
  3. spring_arm_update     — 弹簧臂平滑跟随 + 碰撞检测
  4. camera_transition     — 处理模式过渡动画
  5. camera_shake          — 叠加震屏偏移
  6. camera_fov_animate    — 平滑 FOV 变化

PostUpdate:
  7. camera_apply_transform — 最终应用 Transform
```

## 三、运镜功能详解

### 3.1 弹簧臂平滑跟随

每帧执行：

1. 计算理想位置：`desired_pos = target_pos + target_offset`（世界空间）
2. **碰撞检测**：从 target_pos 向 desired_pos 做球体射线检测
3. 碰到障碍物时将相机沿法线方向推近，限制在 [min_distance, max_distance] 区间
4. 位置平滑插值：`current_offset = lerp(current_offset, desired_pos - target_pos, dt * smooth_speed)`
5. 注视点也做轻微平滑：`look_target = target_pos + look_offset`

### 3.2 相机碰撞检测

- 从玩家位置向相机理想位置做**球体射线检测**
- 碰到障碍物（墙壁、柱子）时将相机推近
- 离开障碍物范围后平滑恢复
- 碰撞几何复用现有的 `CollisionShape` 系统 / `RayCast3d`

### 3.3 震屏效果

支持多种震屏类型：

| 类型 | 触发场景 | 强度 | 频率 | 持续 |
|------|---------|------|------|------|
| 轻震 | 落地、采集 | 0.05 | 30Hz | 0.1s |
| 中震 | 受击、爆炸 | 0.15 | 20Hz | 0.3s |
| 强震 | Boss 登场、建筑坍塌 | 0.3 | 10Hz | 0.5s |
| 持续震 | 地震、引擎轰鸣 | 0.08 | 15Hz | 2.0s |

**实现方式**：在相机最终 transform 上叠加基于时间的高频正弦/Perlin 噪声偏移。

公式：
```
offset_x = intensity * sin(elapsed * frequency * 2π + phase_x)
offset_y = intensity * sin(elapsed * frequency * 2π + phase_y) * 0.7
```

### 3.4 FOV 动态变化

| 情景 | FOV 变化 | 过渡时间 |
|------|---------|---------|
| 冲刺 | 60° → 70° | 0.2s |
| 受击 | 60° → 55° | 0.1s |
| 瞄准 | 60° → 35° | 0.2s |
| 对话 | 60° → 45° | 0.5s |
| 暂停 | 60° → 50° | 0.3s |

## 四、镜头切换方案

### 4.1 切换触发器

**玩家手动切换：**

| 按键 | 功能 |
|------|------|
| V 键 | 循环第三人称距离（近/中/远） |
| Ctrl | 临时切换到瞄准模式 |
| Alt | 自由环绕观察 |
| F5 | 第一人称 / 第三人称切换 |

**游戏事件自动切换：**

| 事件 | 运镜行为 |
|------|---------|
| 进入对话 | DialogueShot — NPC 和玩家双人构图 |
| 进入战斗 | 拉远 + 略微俯角 |
| Boss 登场 | Cinematic — 从 Boss 方向往玩家推 |
| 关卡开始 | 鸟瞰建立镜头 → 下降到玩家身后 |
| 关卡完成 | 拉远环绕展示 |
| 玩家死亡 | 慢动作拉远 |
| 拾取关键道具 | 短暂特写道具 1 秒 |

### 4.2 过渡曲线

使用 `EasingFunction` 枚举：

| 曲线 | 适用场景 |
|------|---------|
| EaseInOutCubic | 通用过渡（默认） |
| EaseOutBack | 弹性"回弹"入场 |
| EaseInOutQuad | 快速切入切出 |
| EaseOutExpo | 长距离推拉 |
| Linear | 震屏恢复 |

### 4.3 对话运镜（DialogueShot）

```
进入对话时：
1. 找到玩家和 NPC 的中点
2. 相机移至中点前方 3 米，略微偏上
3. FOV 缩小到 45°
4. 0.5 秒过渡动画
5. 玩家/NPC 谁说话，相机轻微向谁偏移（weighted look-at）
6. 退出对话时恢复第三人称

公式：
  mid_point = (player_pos + npc_pos) / 2
  dir_to_camera = normalize(npc_pos - player_pos)  // 垂直于对话轴
  camera_pos = mid_point + cross(dir_to_camera, up) * 3.0 + up * 0.5
  look_target = mid_point + up * 1.5
```

### 4.4 过场运镜（Cinematic）

脚本化运镜通过关键帧路径定义：

```rust
struct CinematicKeyframe {
    timestamp: f32,             // 秒
    position: Vec3,
    look_at: Vec3,
    fov: f32,
    easing: EasingFunction,
}

struct CinematicSequence {
    keyframes: Vec<CinematicKeyframe>,
    duration: f32,
    auto_advance: bool,         // 是否自动推进到下一个镜头
}
```

常见过场镜头类型：

| 镜头 | 描述 |
|------|------|
| 建立镜头（Establishing） | 大远景 → 推进到玩家位置 |
| 跟拍（Tracking） | 侧面跟随玩家移动 |
| 特写（Close-up） | 聚焦 NPC 面部/关键道具 |
| 环绕（Orbit） | 围绕目标 360° 旋转 |
| 俯拍（Overhead） | 正上方俯视 |
| 低角度（Low Angle） | 从下往上，强调压迫感 |

## 六、实施优先级

| 优先级 | 功能 | 工作量 | 理由 |
|--------|------|--------|------|
| **P0** | 弹簧臂平滑跟随 | 小 | 立即提升操控手感 |
| **P0** | 相机碰撞检测 | 小 | 防止穿模，基础体验保障 |
| **P1** | 模式切换（近/中/远距离） | 中 | 玩家自定义操控空间 |
| **P1** | 对话运镜 | 中 | 对话系统已有，提升叙事 |
| **P2** | 震屏系统 | 小 | 提升打击感和沉浸感 |
| **P2** | FOV 动态变化 | 小 | 冲刺/受击即时反馈 |
| **P3** | 脚本化过场运镜 | 大 | 需要路径编辑器/关键帧系统 |
| **P3** | 第一人称模式 | 中 | 涉及游戏机制联动 |

## 七、Easing 函数参考实现

```rust
fn ease_in_out_cubic(t: f32) -> f32 {
    if t < 0.5 {
        4.0 * t * t * t
    } else {
        1.0 - (-2.0 * t + 2.0).powi(3) / 2.0
    }
}

fn ease_out_back(t: f32) -> f32 {
    let c1 = 1.70158;
    let c3 = c1 + 1.0;
    1.0 + c3 * (t - 1.0).powi(3) + c1 * (t - 1.0).powi(2)
}

fn ease_out_expo(t: f32) -> f32 {
    if t >= 1.0 {
        1.0
    } else {
        1.0 - 2.0_f32.powf(-10.0 * t)
    }
}
```

## 八、与现有系统的集成点

| 现有系统 | 集成方式 |
|---------|---------|
| `camera.rs` | 重构为 `camera/` 模块，保留现有 LookState 逻辑 |
| `player.rs` | CameraTarget 引用玩家实体，释放键盘切换事件 |
| `dialogue.rs` | 进入对话时触发 `CameraMode::DialogueShot` |
| `combat.rs` | 受击时触发震屏，Boss 出现时触发过场运镜 |
| `game_state.rs` | GamePhase 变更触发对应运镜（Paused → FOV 缩小等） |
| `level.rs` | 关卡加载/完成触发建立/收尾镜头 |
| `collision.rs` | 弹簧臂复用碰撞几何做射线检测 |
| `solari_demo.rs` | CameraControllerPlugin 保持独立，不做改动 |
